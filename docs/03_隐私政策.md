## 一 图片及元数据

1. 您主动选择的照片、图片尺寸、编辑参数、水印文字和素材用于在设备上预览、合成、精修及导出。普通图片处理不主动将照片上传开发者业务服务器，也不后台扫描或上传整个图库。没有云端 AI、人工精修、云相册或作品公开社区。
2. 开启 EXIF 读取时，可从选定照片读取相机、镜头、光圈、快门、ISO、拍摄时间及文件内已有地点文字。这不是设备实时定位。关闭该选项仅影响后续导入，不会自动删除已填入的水印文字；目前该编辑偏好在应用重启后可能恢复默认，不能将其描述为永久撤回所有位置处理。
3. 我们不因普通图片调色提取人脸身份特征，不因基础编辑要求上传身份证。照片本身可能含面部、证件、健康、儿童或其他敏感内容，请在有权处理的范围内使用。
4. 不能保证所有导出文件都清除全部元数据，请在分享前检查姓名、地点、时间及图片内容。主动向客服发邮件或附图是另外的数据传输场景，请遮挡无关敏感信息。
5. 本地头像仅保存在应用沙盒，用于设备上的账号展示，不由头像功能上传至 Supabase 用户资料。图片导出会在用户主动保存且获得所需权限时写入系统相册。

## 二 账号 购买与客服

### 注册及登录

配置了 Supabase 项目时，邮箱注册、验证码验证和登录直接使用 Supabase Auth，处理邮箱、必要认证信息、账号标识、会话及安全连接记录。认证密码经加密连接提交给认证服务，不在应用本地资料中明文保存，也不应提交给客服。

Apple 登录接收 Apple 实际授权的用户标识、姓名或邮箱；配置了托管认证时，身份令牌交由 Supabase 核验，否则使用应用当前支持的本机资料方案。Apple 隐藏邮箱是否可用以实际授权为准。应用不获取 Apple 密码。

本机账号资料可能保存在 SecureStore；Supabase 会话由 SDK 当前配置的本地存储保存，不能将全部会话存储统称为 SecureStore 加密。托管认证服务仍可能保存账号和登录安全记录，退出登录或卸载不会自动删除这些资料。

当前基础水印功能可不登录使用，Pro 和购买／恢复流程要求应用账号登录；拒绝提供非必要头像等资料不影响不依赖该资料的功能。没有以该资料建立云端照片档案或云端订单迁移。

### 购买与权益

应用通过 Apple StoreKit 在设备上查询有效购买、商品标识、购买或到期时间及退款／撤销状态，用于交付和恢复权益。固定期限依据本机可获得的有效交易时间计算；没有另建开发者云端交易验证或账号权益数据库。

购买权益跟随付款时的 Apple 账户，不独占绑定某一个应用账号。Apple 的交易和购买记录由 Apple 管理；应用不因内购获得完整银行卡、Apple 密码或支付密码。当前版本不为提醒发送而额外上传交易标识或登记收件邮箱。

### 客服及删除申请

客服入口或账号删除申请入口会请求系统打开邮件应用，预填主题；账号删除草稿仅包括本机已知的应用账号标识、登录方式和请求说明，不包括密码、验证码、身份令牌或照片附件。用户仍需自行检查并发送。打开草稿不等于请求已发送、已受理或已完成处理。

客服邮件通过 soratani@126.com 在 126 邮箱收取，不启用自动转发，也不接入其他客服平台；账号删除申请使用相同收件渠道。客服邮件和账号删除申请由运营者刘伟本人在中国大陆查阅和人工处理。我们处理实际收到的发件地址、请求说明和解决问题所必需的信息；外部邮件提供方也按其规则处理邮件。人工处理地点不等于邮件服务商服务器或支持访问仅位于中国大陆，后者仍需单独核验。无后台工单系统、自动 SLA 计时或删除回执服务，不承诺可以在 App 中查询远端处理进度；通过回复邮件或另行联系确认进度与结果。普通客服邮件及问题截图等附件在问题处理结束后删除；涉及订单收据、退款争议或投诉的资料另行区分，当前尚无固定保留期限，具体保留依据、期限及删除条件仍需在发布前明确，不能将此写为永久保存承诺。以上删除规则针对运营者可控制的资料，不表示邮件服务商全部备份会同时清除。

### 运营者持有的手动导出资料

运营者曾从托管账号资料中手动导出用户标识、邮箱或个人资料，目前仍保留在刘伟本人位于中国大陆的设备上，不进行云端同步或备份。这些资料用于用户信息核对，使用完即删除；办理账号删除申请时一并清除该用户对应的导出资料。其属于运营者另行持有的个人信息副本，不是云端作品库，也不因没有自建业务后端而免于本政策所述保护和删除义务。

## 三 诊断与版本更新

1. 正式发行版本不启用 Sentry，不初始化 Sentry 诊断客户端，不通过 Sentry 上报错误事件、日志、用户上下文、请求内容、性能数据、截图或回放，也不提供可以开启 Sentry 的开关。Apple 系统或平台独立处理的诊断信息不因此成为开发者通过 Sentry 收集的数据。
2. 正式发行版本不启用 Expo／EAS Update 热更新，不在应用运行时通过该更新服务检查或下载新的应用代码；版本更新仅通过 App Store 安装包提供。开发构建、工程预览或构建服务与面向终端用户的热更新不同，不据此声称应用完全离线。
3. 过去开发或测试版本曾向 Sentry 上传记录，后台历史记录目前尚未清理，现用于异常信息排查和问题分析，问题处理完成后即删除，以处理完成为删除条件，不另设固定天数。当前停用不代表这些记录已经删除；历史事件的实际字段、数据范围、存储地区及清理规则的执行情况仍需依据后台记录核验，不将新版本停用或新配置的限制追溯描述为历史版本从未处理过相关信息。
4. 账号认证及用户主动选择的购买、客服等联网处理仍按实际服务及处理依据进行。未来若重新启用诊断或热更新，应先更新具体告知，核验真实数据范围和服务配置，并依法完成必要授权，不沿用本版“未启用”的描述。

## 四 系统权限及本地控制

1. 照片选择和读取用于主动导入图片、素材或头像，保存权限用于将结果写入相册。实际依系统选择器、有限授权和发行版本表现为准；拒绝相应权限不影响无须该权限的功能。
2. 基础功能不要求通讯录、麦克风、实时定位或广告追踪。新增相机等能力时应在相应功能中逐项说明并按需请求。
3. 可在系统设置中调整权限。撤回后停止对应的新访问，但不自动清除此前合法生成的本地内容、系统相册或用户主动发送到其他服务的文件。
4. 个人中心 → 账号与本机资料 → 清除本机资料并退出登录，会尝试删除本机账号资料和头像并退出当前会话。该操作不清除全部图片缓存、不重置全部编辑偏好、不删除托管账号、不撤销 Apple 登录授权，也不取消订阅。
5. 图片临时文件由应用和系统实际缓存机制管理，目前没有统一的一键图片缓存清理入口或保证周期。卸载可能删除应用沙盒内容，但 SecureStore／Keychain、系统备份、相册及外部服务可能有不同保留机制，不承诺卸载即删除全部资料。
